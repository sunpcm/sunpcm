# 你好，我是 sunpcm

**关注 AI 应用、Agent 工作流，以及让它们可靠交付的工程基础。**

[English](README.md) · [查看技术收藏](https://github.com/sunpcm?tab=stars)

我主要使用 Python 和 TypeScript，探索实时语音应用、计算机视觉、全栈开发与 Linux 自动化。比起工具本身，我更关注清晰的接口、可复现的结果，以及模型和供应商变化后仍能持续维护的系统。

## 工作方式

- 工程知识独立于具体 AI 编程工具，便于迁移和持续维护。
- 小步开发，通过独立审查和验证确认结果。
- 将测试、评估证据与部署检查纳入交付过程。
- 从实验中提炼可复用的工具，同时记录能力边界。

**常用技术：** Python · TypeScript · React · FastAPI · PostgreSQL · Docker · Ansible
